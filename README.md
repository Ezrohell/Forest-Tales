
## ⚙️ Configuration & Customisation

**Language:** The game supports Indonesian (`id`), US English (`en-US`), and UK English (`en-UK`). Language can be changed in the settings menu. 🌍

**Sensitivity:** Adjust joystick sensitivity via the settings menu. The value is stored in `localStorage` under the key `hutan2d_sens`.

**Progress:** Progress is saved automatically in `localStorage` under the key `hutan2d_progress`. To reset, clear your browser's local storage for the page.

**Adding New Levels:** Levels are defined in the `LEVELS` array inside the HTML file. Add a new object to extend the game.

**Adding New Enemies:** Enemy types are defined in `ENEMY_TYPES`. You can add new shapes, stats, and colours. 🎨

## 🔒 Privacy

- **100% Offline** — No data is sent to external servers.
- **No Tracking** — No analytics, no ads.
- **Local Storage Only** — All progress and settings are stored on your device. 🔐
